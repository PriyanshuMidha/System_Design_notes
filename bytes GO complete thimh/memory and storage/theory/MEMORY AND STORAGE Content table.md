## Complete notes

Memory and storage topic map:

- [[Memory]] explains temporary working memory.
- [[RAM]] and [[ROM]] explain main memory types.
- [[DRAM]], [[SRAM]], [[DDR SDRAM]], and [[GDDRM SDRM]] explain memory technologies.
- [[HDD]] and [[Storages]] explain permanent storage.
- [[BIOS]] and [[Firewares]] explain low-level system software.

## Must know

- Memory is fast and temporary.
- Storage is slower but permanent.
- Firmware controls hardware at a low level.
